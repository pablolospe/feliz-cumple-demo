# 🎉 Feliz Cumple Sofi — Portfolio Demo

> **Demo interactiva para portfolio:** Aplicación web con experiencia gamificada y personal diseñada como regalo sorpresa de cumpleaños (30 años). 
> 
> *Nota: Todo el contenido audiovisual y nombres en esta versión son ficticios (generados con IA y stock curado), preservando la privacidad del proyecto original y demostrando la capacidad de producto, UX emocional y arquitectura frontend.*

---

## 🌟 Funcionalidades y Experiencia de Usuario

- **🔐 Puerta de Acceso Gamificada (Password Gate):** 
  - Protección de acceso mediante contraseña secreta con animaciones y confeti celebratorio (`canvas-confetti`).
  - Para propósitos de demo en portfolio, la clave es pública: **`sofi30`** (con atajo para autocompletar e ingresar en un clic).
- **🗺️ Hub de Desbloqueo Progresivo:**
  - Sistema de 4 etapas que se van desbloqueando secuencialmente respondiendo preguntas de complicidad y anécdotas compartidas.
  - Barra de progreso interactiva y feedback visual con animaciones de éxito.
- **📸 Galería de Recuerdos Curada:**
  - Filtros por categorías temáticas (*Recuerdos Especiales, Amigas, Viajes, Familia*), etiquetas interactivas y buscador dinámico.
  - Modal lightbox de pantalla completa con soporte de navegación por teclado y botón para mezclar fotos aleatoriamente (Shuffle).
- **💌 Saludos y Dedicatorias:**
  - Tarjetas de dedicatorias cálidas con avatares, roles afectivos, reacciones de corazón y filtro por grupos.
- **🎵 Videos y Serenatas:**
  - Reproductor con facade optimizado para YouTube / videos verticales.
- **✨ Easter Egg Oculto:**
  - Disparador en el footer con un acertijo secreto que premia la curiosidad del usuario.

---

## 🛠️ Stack Tecnológico

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Estilos:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconografía:** [Lucide Icons](https://lucide.dev/)
- **Efectos:** Canvas Confetti
- **Tipografía y UI:** Diseño oscuro inmersivo (*Dark luxury / Festivo*) con paleta oro y magenta suave (`#c9a84c`, `#241d36`, `#0d0a14`).

---

## 🚀 Cómo ejecutar en desarrollo

1. **Instalar dependencias:**
   ```bash
   npm install
   # o
   bun install
   ```

2. **Iniciar servidor local:**
   ```bash
   npm run dev
   # o
   bun dev
   ```

3. **Abrir en el navegador:**
   - Ingresar a [http://localhost:3000](http://localhost:3000).
   - Clave demo: `sofi30`.
